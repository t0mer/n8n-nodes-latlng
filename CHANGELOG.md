# Changelog

## 2026.9.0

- First release.
- Geocoding: Forward and Reverse.
- Place: Search, Nearby, Autosuggest and Get Categories.
- Static Map: Get Image, returned as binary data.
- Tile and Dataset: TileJSON metadata and vector tiles, using a Maps key.
- Options: Simplify, Return Empty Item, Include Rate Limit Info, Language and Timeout.
- Retries 429 and 5xx responses, and never puts keys in output or error messages.
